# ExpertSystem / Экспертная Система

Экспертная система с **прямой цепочкой рассуждений** и веб-интерфейсом на ASP.NET Core.
Предметная область: **подбор комплектующих для ПК**.

Лабораторная работа №1 по дисциплине «Системы искусственного интеллекта»
([LRDescription.md](LRDescription.md)).

## Возможности

- Правила вида `ЕСЛИ Объект1=Значение1 [И Объект2=Значение2 ...] ТО Объект3=Значение3`.
- База правил хранится **отдельно от программы** в текстовом файле `rulesets.rs` (JSON).
- Редактирование базы правил в браузере: добавление, изменение, удаление.
- Импорт и экспорт базы правил файлом.
- Запуск вывода по заданной стартовой ситуации, с указанием, каким правилом получен каждый факт в ходе рассуждений.
- Подсказка, каких сведений не хватает, если вывод остановился.
- Готовая база из 71 правила для подбора ПК
  ([RuleBase.md](RuleBase.md)).

## Быстрый старт

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```bash
cd ExpertSystem.WebApp
dotnet run --launch-profile http
```

Приложение откроется в [http://localhost:5147](http://localhost:5147).

> Файл с правилами уже подложен и будет загружен при открытии веб-приложения.
> Unit-тесты возможно запустить следующим образом:

```bash
dotnet test
```

## Как пользоваться

1. **Свод правил**. Клик по карточке выбирает правило, после чего
   доступны кнопки «Редактировать» и «Удалить». «Добавить правило» открывает форму, в которой
   можно добавлять и убирать условия (`И`). Все изменения сразу сохраняются в `rulesets.rs`.
   «Экспорт правил» скачивает текущий свод правил, «Импорт правил» **заменяет** его загруженным файлом.
2. **Рассуждение.** Введите стартовую ситуацию - известные факты вида «Объект = Значение» и нажмите
   кнопку запуска. Ниже появятся вывод, рабочая база данных и ход рассуждений.
   Если чего-то не хватило, система назовёт объекты, о которых нужны сведения;
   добавьте их в стартовую ситуацию и запустите снова.

### Пример

Входные данные:

| Объект | Значение |
| --- | --- |
| Назначение | Игровой |
| Бюджет | Средний |
| Разрешение монитора | 1440p |
| Платформа | AMD |
| Форм-фактор | Стандартный |

Система выведет класс сборки («Высокий»), затем процессор (Ryzen 7 7700), сокет (AM5),
тип и объём памяти, материнскую плату, видеокарту (RTX 4070 Super), блок питания,
охлаждение, накопитель и корпус - всего 11 новых фактов.

Допустимые значения входных объектов: Назначение: Офисный / Мультимедийный / Игровой /
Рабочая станция; Бюджет: Низкий / Средний / Высокий; Разрешение монитора: 1080p / 1440p / 4K;
Платформа: Intel / AMD; Форм-фактор: Стандартный / Компактный.
Ни одного правила не сработает, если задать только часть из них
(например, для игрового ПК нужны и назначение, и бюджет).

### Формат файла с правилами

```json
[
  {
    "Conditions": [
      { "Object": "Назначение", "Value": "Игровой" },
      { "Object": "Бюджет", "Value": "Средний" }
    ],
    "Consequence": { "Object": "Класс сборки", "Value": "Высокий" }
  }
]
```

Каждое правило должно содержать хотя бы одно условие и следствие; объект и значение не пустые.
При импорте это проверяется, при ошибке текущая база остаётся без изменений.

### Структура репозитория

| Путь | Назначение |
| --- | --- |
| `ExpertSystem.Core` | Модели (`Match`, `RuleSet`, `InferenceResult`), вывод (`Expert`), чтение/запись базы (`Parser`) |
| `ExpertSystem.WebApp` | Razor Pages: `Index` (свод правил), `Inference` (запуск рассуждения), `About` |
| `ExpertSystem.WebApp/rulesets.rs` | База правил |
| `ExpertSystem.Tests` | Тесты xUnit для ядра и парсера |
| `RuleBase.md` | База правил в виде «ЕСЛИ … ТО …» |
